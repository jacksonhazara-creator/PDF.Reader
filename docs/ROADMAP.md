# Roadmap

Each phase ships as its own release before the next starts.

## Phase 1: fast, beautiful reader ✅ (v0.1)
Open, render, scroll, zoom, search, select & copy, print · start screen, tabs, recents,
thumbnails, bookmarks · page colors · reading mode · read aloud · session restore ·
command palette · Settings → Updates · installer + portable build.

Follow-ups: multi-page text selection, pinch-to-zoom on touch screens, double-click word
selection, arm64 build.

## Phase 2: annotate & organize
Highlight / underline / strikethrough, sticky notes, freehand ink (pen pressure), shapes ·
Edit text: add text · standard PDF annotations, auto-save + crash recovery, unlimited
undo/redo · notes panel with .txt/.md export · customizable toolbar (pin from All tools,
drag to reorder, position, labels, reset) · organize pages, combine, split · fill forms ·
Fill & Sign · side-by-side view.

## Phase 3: tools
Edit text: erase & replace (true removal via the redaction engine) · true redaction with
verification · AES-256 protect / remove password · clean before sharing · compress ·
export images/text, images → PDF · offline OCR (Windows.Media.Ocr) · page numbers,
watermarks, stamps · flatten.

## Phase 4: advanced
Compare PDFs · prepare forms · certificate signatures · PDF → Word · Explorer thumbnail and
preview handlers · optional "set as default PDF app" in Settings.
